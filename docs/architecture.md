# NOVA Architecture

NOVA is a digital civilization platform. The current web layer is a React/Vite single-page application designed around a future citizen operating system.

## Experience layer

- Home: civilization overview and founding mission
- Cities: eight specialized digital territories
- Innovation: Dream Factory pipeline and project discovery
- Economy: conceptual Nexa economy
- Constitution: civic framework
- Citizenship: identity onboarding
- Dashboard: Citizen OS foundation

## Future platform services

The application is structured so persistent services can later provide authentication, digital passports, project records, collaboration, civic participation, research, education, marketplaces and AI-assisted tools. AI should assist rather than hold unaccountable sovereign authority.

## Design principle

NOVA should feel like entering a digital country: coherent civic identity, places, institutions, economy, projects and culture—not a generic social network or game.
